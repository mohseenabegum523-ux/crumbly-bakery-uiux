# Crumbly – Bakery E-Commerce UI/UX

Crumbly is a mobile bakery e-commerce application designed using Figma.

## Project Overview

A modern and user-friendly mobile application for browsing,
searching, and purchasing bakery products.

## Features

- User Login
- Home Page
- Product Listing
- Product Details
- Shopping Cart
- Checkout
- Payment
- User Profile

## Tools Used

- Figma
- Google Fonts – Poppins

## UI/UX Design

Designed using Figma with reusable components and an interactive prototype.
